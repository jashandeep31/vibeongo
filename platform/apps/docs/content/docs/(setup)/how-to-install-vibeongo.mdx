# How to install Vibeongo

Vibeongo brings remote vibe coding to your phone. Use the Android app to
connect to your cloud workspace and work with an AI coding assistant from
anywhere.

<Callout type="info" title="Download the Android app">
  [Download the latest Vibeongo APK](https://download.vibeongo.com/app-release.apk),
  then open the downloaded file on your Android device to install it.
</Callout>

## Install the testing release

Use the same Google account for all three links, including the Play Store on
your Android device.

1. [Join the Vibeongo Google Group](https://groups.google.com/g/vibeongo).
2. [Opt in as a tester](https://play.google.com/apps/testing/com.vibeongo.app)
   and select **Become a tester**.
3. [Install Vibeongo from Google Play](https://play.google.com/store/apps/details?id=com.vibeongo.app).

If the Play Store says the app is unavailable, wait a few minutes after opting
in, then reopen the listing with the account that joined the test.

## Help us test

Vibeongo is still in testing. A previous Google Play submission was rejected
because there was not enough testing activity, so regular use and honest
feedback are especially valuable.

Credits may be available for serious testers when the budget allows, but they
are not guaranteed. Thank you for helping us improve the app before the wider
release.
